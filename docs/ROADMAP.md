# bdd-workflow — Roadmap

Post-v1 work, deferred by design. v1 ships the three plugins + the `.bdd.json` schema + CI
gates; the KB fetch, domain-hazard externalization, scaffold templates, and eval harness follow.

## Roadmap

1. **Per-model best-version skills + tiered multi-agent delegation** — cheap actions → cheap
   models; a maintained skill variant per agent tier.
2. **Public eval corpus + independently reproducible perf matrix.**
3. **Publish `kb-builder` (R3)** once the attribution refactor lands.
4. **Attribution primitive** — per-claim inline anchors, a claim-ledger sidecar, evidence
   snapshots, and a Falsifier verification gate before publish.
5. **Eval tier-2** — headless Claude Code optimizing whole `SKILL.md` files, not just embedded
   prompts.
6. **BDD detection index + watcher** — replace the per-prompt filesystem walk with an atomic
   index file (`${CLAUDE_PLUGIN_DATA}/index/<project-hash>.json`) written by a single-instance
   watcher (started on `SessionStart`, pidfile + lock, fswatch/inotify + polling fallback). The
   watcher touches a heartbeat on every run; per-prompt cost becomes one `stat` of the index
   mtime; a stale heartbeat triggers a debounced, bounded restart. Generalizes to a reusable
   project-index primitive any hook can read.
7. **KB per-page provenance + citations** — the KB has no per-page source citations today
   (surfaced by the POC-3 publishability audit); add per-page provenance before broadening the
   outbound license claim, and feed it into the attribution primitive (item 4).

## Deferred from the de-risking review

- **Community-marketplace submission** — v1 is manual `/plugin marketplace add`; submit to a
  community marketplace after the fetch-hook design settles (the fetch hook is kept
  screening-friendly now so this needs no rework).
- **Public CI gate running `claude plugin validate` / `eval` + published perf matrix** — pending
  confirmation the CLI runs in a stock GitHub Actions runner (POC 1). Until then `make validate`
  is the documented local gate.
